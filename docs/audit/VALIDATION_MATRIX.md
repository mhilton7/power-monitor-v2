# Validation matrix

This matrix preserves the rc.5-preparation audit snapshot and records explicitly
identified supplemental rc.6 working-tree evidence. Server rc.6 later
completed publication and remains public and installable with its attached
assets. Hardware execution confirmed that firmware rc.1 through rc.5 crash in
the main stack before provisioning; coordinated rc.8 publication is pending.
Historical rows are not relabeled as rc.8 evidence; rows naming
revision 0012, 31 Vitest tests, or the live tiered-page probe are supplemental
current-source results.

Status terms:

- **Local pass**: the stated command/test ran successfully against this working
  tree during the repair session.
- **Implemented; final gate pending**: code and tests exist, but the complete
  current-source gate has not produced retained passing evidence.
- **Historical pass only**: evidence belongs to immutable public rc.3 or an
  earlier firmware commit and is not evidence for this working tree.
- **Historical failed publication**: a named rc.4 gate result is preserved
  exactly but cannot be promoted to a later release pass.
- **External pending**: TrueNAS, publication, or marked hardware is required.
